02 · NÉBULEUSE

À propos

Tout a commencé par une curiosité : comprendre comment les choses fonctionnent derrière l'écran. Cette curiosité est devenue une discipline, puis une direction.

Aujourd'hui, j'apprends le développement web avec méthode — chaque projet est une mission, chaque bug une anomalie à résoudre, chaque déploiement un petit lancement.

Ma vision : construire des expériences web qui donnent autant de plaisir à utiliser qu'à fabriquer.

04 · MISSIONS

Journaux de mission

EN LIGNE DÉPART — 2026.10

Énora Cosmetics

Une vraie boutique en ligne de soins du corps, livrée à Dakar. Next.js et TypeScript pour le site, Supabase pour la base de données, les comptes et les photos. On commande en une seule page (paiement à la livraison, Wave, Orange Money ou WhatsApp) : le total, le stock et le code promo sont vérifiés en base dans une même transaction. Un back-office gère commandes, stocks, produits, avis et articles. Accès protégés table par table (RLS), tests Vitest et Playwright.

  • Next.js
  • TypeScript
  • Supabase
  • Tailwind CSS

EN LIGNE DÉPART — 2026.03

Xibaar Yi

« Les nouvelles », en wolof : un site d'actualité sénégalaise en PHP et MySQL, sans framework. Les vrais titres des médias sénégalais arrivent automatiquement par flux RSS, les commentaires sont modérés, et un back-office gère les rôles. Sessions, protection CSRF, envoi d'images : j'ai tout écrit à la main pour comprendre ce que font les frameworks. Projet d'équipe à l'ESP, que je maintiens et sécurise depuis.

  • PHP 8
  • MySQL
  • JavaScript
  • Apache
